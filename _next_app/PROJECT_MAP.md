# Project map

- `src/` contains the faculty dashboard, student check-in page, browser API client, and Firebase web authentication.
- `server/index.js` exposes the Express API and serves the built frontend.
- `server/database.js` stores local attendance in SQLite. `server/postgres-store.js` supports hosted PostgreSQL. `server/firestore-store.js` supports Firestore mode.
- `scripts/migrate-firestore-to-postgres.js` migrates data when the deployment changes storage.
- `public/` contains the production frontend generated by `npm run build`.

Use the root `README.md` for setup and deployment. Keep `.env`, credentials, and local `data/` out of Git.
